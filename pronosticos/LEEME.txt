PRONOSTICOS - se actualiza solo cada dia (GitHub gratis; se hace desde el ordenador)
1. Crea cuenta en github.com y un repositorio PUBLICO nuevo, p. ej. "pronosticos" (New repository).
2. Add file -> Upload files: arrastra index.html, data.json, build.py, manifest.webmanifest, sw.js, icon-180.png, icon-512.png. Commit.
3. Add file -> Create new file. En el nombre escribe: .github/workflows/daily.yml  (las barras crean las carpetas).
   Pega dentro el contenido del archivo daily.yml de este zip. Commit.
4. Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, carpeta / (root) -> Save.
   Tu web sera https://TU-USUARIO.github.io/pronosticos/
5. Pestana Actions -> "Actualizar pronosticos" -> Run workflow (primera vez, a mano). En ~1 minuto se llena data.json.
   Despues se ejecuta solo cada dia. Si GitHub lo pausa por inactividad, pulsa "Enable workflow".
6. iPhone: abre la web en Safari -> Compartir -> Anadir a pantalla de inicio.
